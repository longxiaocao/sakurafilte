### 🔴 Bash 工具对「docker exec + 长耗时写命令」的坑（必须记）
- `docker exec ... psql -c "TRUNCATE...; INSERT..."` 或 `psql -f <大SQL>` 这类**耗时较长（>~数十秒）的写操作**，Bash 工具会**静默返回空 stdout + 退出码 1**，但实际命令可能在后台仍跑（或已执行）。而瞬时读（`SELECT 42`、小文件 `-f`）正常。
- 对策：① 长写命令一律用 `run_in_background`（nohup + 后台），结果写文件再 `tail`；② 或改用 Python `subprocess.run(["docker","exec",...,"psql",...])` 捕获 RC/stdout。本轮 seed 字典表就是这样跑完的（6分52秒，DO 块成功填充 8 表）。
- 注意 `docker exec psql -i` 在无 TTY 时会立即退出 1（交互模式 stdin 关闭）→ 不要给 psql 加 `-i`。
