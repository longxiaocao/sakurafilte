## 三、问题清单（按严重程度分类）

### 🔴 阻塞（P0）：无

### 🟠 严重（P1）：无

### 🟡 一般（P2）：1 项

**P2-1 聚合搜索：URL 带 `?q=` 不自动触发搜索**
- **现象**：在全局搜索框输入关键词回车 → 仅展开联想建议，URL 变为 `?q=oil`，但**结果区不渲染**，必须再点"搜索"按钮才出结果。
- **复现**：①打开 `/search/aggregate` ②在顶部全局搜索框输入 `oil` ③回车 → 联想收起，结果区为空（URL 已带 q 参数）。
- **影响范围**：所有从搜索框回车进入的用户（包括从外部带 `?q=` 参数分享的链接）首次看到空结果区，造成"搜索无结果"的困惑。
- **修复建议**：在聚合搜索视图 onMounted/路由守卫中检测 `route.query.q`，非空则自动执行一次搜索；或把"回车"语义从"仅填词"改为"填词 + 触发搜索"。

### 🟢 轻微（P3）：3 项

**P3-1 编辑页标题对非法 ID 显示 `#NaN`**
- **现象**：`/admin/products/MR01000000/edit`（:id 应为数字 ID）→ API 404 提示正常，但页面标题显示 `Edit Product #NaN`。
- **影响**：仅错误路径的标题文案不友好，不影响功能。
- **建议**：:id 非数字时显示"产品不存在"标题而非 `#NaN`。

**P3-2 性能监控页 P95=787ms 警告（≥500ms）**
- **现象**：`/admin/perf` 显示 `⚠ Warning · P95 = 787ms`。
- **说明**：API 层实测聚合搜索 P95=48ms（curl 采样）；787ms 来自后端埋点，口径可能含富化回源/缓存未命中等场景。**需核实是采样口径差异还是真实慢请求**（监控页有具体端点明细可查）。
- **建议**：抽查 perf 页的端点明细，定位是否有个别慢端点（如富化未命中时的 PG 查询）。

**P3-3 机型目录数据 4.2MB（首次加载 ~4s）**
- **现象**：`catalog` 接口返回 4.2MB JSON（机型分类目录），首次加载耗时 3.9s。
- **影响**：低端网络下首屏变慢（已缓存后无感）。
- **建议**：目录数据可考虑压缩（gzip 已在 nginx 开启，传输体积会小很多）或懒加载。

### ⚪ 环境说明（非代码问题）

- **详情页"图片 0 张"**：35 张 R2 测试图的 DB 记录被今日 db-migrate 事故清理（R2 对象仍在），恢复数据后图片关联为空属预期；重新上传或迁移时恢复即可，非前端缺陷。
- **agent-browser 对无 `href` 的 router-link 点击不触发**：工具模拟限制，JS 点击跳转正常，非产品问题。
